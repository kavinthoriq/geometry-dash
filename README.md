# 🔷 Geometry Dash

Game platformer **bertema ritme ala Geometry Dash** yang bisa dimainkan langsung di browser. Lompat, hindari rintangan, dan bertahan sampai akhir level!

## ✨ Fitur

- **Gameplay satu tombol**: cukup satu input untuk melompat dan menghindari rintangan.
- **Rintangan khas Geometry Dash**: spike, platform, dan pola yang menuntut ketepatan waktu.
- **Langsung main di browser**: tanpa instalasi, tanpa akun.
- **Ringan & mudah diakses**: bisa dibuka lewat PC maupun perangkat lain yang punya browser modern.

## 🚀 Cara Menjalankan

### 1. Main Online (paling mudah)
Buka tautan demo di atas dari browser seperti Chrome, Firefox, atau Edge.

### 2. Jalankan Secara Lokal

```bash
# Clone repository
git clone https://github.com/kavinthoriq/geometry-dash.git
cd geometry-dash

# Jalankan server lokal (pilih salah satu)
npx http-server        # jika memakai Node.js
python -m http.server  # jika memakai Python
```

Lalu buka `http://localhost:8080` (http-server) atau `http://localhost:8000` (Python) di browser.
